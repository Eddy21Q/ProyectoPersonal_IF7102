# ProyectoPersonal_IF7102

Repositorio del Proyecto Personal del curso IF7102 Multimedios, I Ciclo 2026.

La aplicacion principal se encuentra en la carpeta:

```txt
PortafolioMultimedia/
```

## Framework Utilizado

- Vue 3
- Composition API
- Vite

## Ejecucion del Proyecto

Desde la raiz del repositorio:

```sh
cd PortafolioMultimedia
npm install
npm run dev
```

Luego abrir la URL indicada por Vite, normalmente:

```txt
http://localhost:5173/
```

## Publicacion en GitHub Pages

Desde la carpeta del proyecto:

```sh
cd PortafolioMultimedia
npm run deploy
```

Este comando genera la carpeta `dist` y la publica en la rama `gh-pages`.

## Archivos Importantes

- `PortafolioMultimedia/README.md`: instrucciones completas, capturas y descripcion tecnica.
- `REFERENCIAS.md`: documentacion del proceso de aprendizaje, recursos consultados, fuentes multimedia y apoyo de IA.
- `PortafolioMultimedia/public/data/data.json`: datos cargados dinamicamente por la aplicacion.
